# 🛍️ Baela Commerce

> Projeto em desenvolvimento 🚧

Projeto de uma loja virtual fictícia desenvolvido com foco em praticar desenvolvimento Front-end moderno utilizando HTML, CSS e, futuramente, JavaScript.

O principal objetivo deste projeto é evoluir minhas habilidades em desenvolvimento Front-end através da construção de uma aplicação real, aplicando boas práticas de organização, componentização e responsividade.

---

## 🚀 Objetivos

- Praticar HTML5 Semântico
- Aprender CSS Moderno
- Desenvolver componentes reutilizáveis
- Criar interfaces responsivas
- Evoluir meu portfólio como Desenvolvedor Front-end

---

## 🛠️ Tecnologias

- HTML5
- CSS3
- Google Fonts
- Lucide Icons
- Git
- GitHub
